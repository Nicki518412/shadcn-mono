# 业务规则与 Review 矩阵

本文是业务 Review 的检查基线。变更规则时，同步更新对应 API、前端权限、测试和本表。

## 全局规则

| 主题 | 业务规则 | 必查项 |
|---|---|---|
| 认证 | access token 5 分钟；refresh token 单次轮换；禁用用户的旧 token 立即失效 | 401 语义、轮换重放、改密/强退吊销 |
| 授权 | 多角色权限取严格交集；无角色或任一零授权角色可使有效权限为空 | seed、后端中间件、前端按钮三处同码 |
| 状态变化 | 用户状态、角色状态、菜单状态和角色授权在每次请求时实时生效 | 旧 access token 不得保留已撤销权限 |
| 错误契约 | 成功 `{ code: 0, data, message }`；校验/认证/授权/不存在/冲突分别为 400/401/403/404/409，账号锁定 423 / 发送限流 429 | HTTP 状态与 body.code 同时断言 |
| 数据库 | SQLite/MySQL/PostgreSQL 可移植；不使用方言专属查询 | 唯一字段、可空字段、事务和级联 |

## 模块矩阵

| 模块 | 核心规则与副作用 | API/组件测试 | E2E 关键旅程 |
|---|---|---|---|
| 登录与 OTP | 密码防枚举；5 次失败锁定；OTP 冷却、过期、一次性消费 | 已覆盖成功/失败/并发/过期 | 密码登录、深链恢复、邮箱 OTP 错码 |
| 用户 | 用户名小写；邮箱/手机唯一；禁用立即拒绝旧 token；改密吊销 refresh | CRUD、冲突、导入导出、状态时效 | CRUD、角色分配、禁用、导入导出、个人资料 |
| 角色 | 编码大写；授权全量替换；禁用/撤销立即影响现有 token | CRUD、分页、交集和权限时效 | 创建、删除、授权后导航变化 |
| 菜单 | DIR/MENU/BUTTON 挂载约束；防循环；BUTTON 不生成路由 | 类型组合、父子循环、权限树 | 创建、类型约束、删除 |
| 部门 | 树结构防自挂；删除级联子部门；用户归属可为空 | CRUD 和树约束 | 根/子部门创建、级联删除 |
| 字典 | 类型编码唯一；字典项全量替换；值不重复；禁用项不进 options | CRUD、替换校验、options | 类型创建、字典项保存和持久化回显 |
| 参数 | key 统一小写且唯一；列表/编辑/删除一致 | CRUD、冲突和权限 | CRUD |
| 公告 | 仅已发布公告进入首页 latest；下架后不可见 | CRUD、latest | 发布并展示、删除 |
| 日志 | 登录日志记录成功/失败；写操作记录且敏感体脱敏 | 状态、脱敏、权限 | 登录日志、操作日志和详情 |
| 会话 | 仅未吊销且未过期为在线；单条/用户全量吊销 | 列表、CAS 吊销、revoke-all | 精确目标会话强制下线 |
| 通知 | 查询与已读仅本人；发送需要管理权限 | 隔离、已读、发送权限 | 铃铛、全部已读、发送 |
| 文件 | 仅登录用户；图片 MIME 白名单；2MB；服务端文件名防穿越 | 类型、大小、鉴权、路径 | 头像上传仍待补 |

## 每轮专项 Review

1. 从本表选择一个主题，沿“数据库 → API → OpenAPI → 前端 → 测试”完整追踪。
2. 写接口检查权限码、事务、唯一冲突、日志脱敏与缓存失效。
3. 状态变化检查旧 token、旧页面缓存和其他用户数据隔离。
4. E2E 只覆盖关键跨层旅程；输入边界和竞态放在 API/单元测试。
5. 外部集成（Clerk、真实邮件/短信、三方言数据库）在对应环境单独验收并记录。
